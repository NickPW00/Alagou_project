# Guia de marca do Alag@u

## Nome
Sempre **Alag@u** (com @). Slogan: **Alagou? Avisou!** Subtítulo: **Monitoramento Comunitário de Alagamentos**.
Identificação institucional: **Uma iniciativa do projeto Meninas pelo Clima — LabPENSo/UERJ.**

## Logomarcas institucionais
| Arquivo original (não alterar) | Versão usada no app | Onde aparece |
|---|---|---|
| `originais/meninas-pelo-clima.jpg` | `public/logos/meninas-pelo-clima.webp` (494×520, margem branca externa reduzida) | Início, rodapé, Sobre, Aprenda (módulo 6), README |
| `originais/uerj.jpg` | `public/logos/uerj.webp` (256×256) | Sobre |
| `originais/uerj-febf.jpg` | `public/logos/uerj-febf.webp` (454×144) | Rodapé, Sobre, README |

Regras:
- não recolorir, distorcer, cortar o desenho ou aplicar efeitos;
- como os originais têm fundo branco, usar sempre sobre superfície branca;
- manter o texto alternativo descritivo.

Se a coordenação fornecer versões vetoriais (SVG/PDF) ou com fundo transparente, elas devem substituir as atuais.

### Cores de situação da rua (não seguem a paleta da marca)
São cores de **significado**, escolhidas para contraste (WCAG AA) e leitura imediata, e sempre acompanhadas de texto e ícone:

| Situação | Valor |
|---|---|
| Sem alagamento observado | `#2E7D32` |
| Acúmulo de água | `#F2C200` |
| Rua parcialmente alagada | `#EF6C00` |
| Rua totalmente alagada | `#C62828` |
| Desconhecida ou desatualizada | `#757575` / `#8A8A8A` |
